# Shopping List App – Frontend (Nuxt 3)

Welcome to the frontend of my Shopping List App!
This project is built with **Nuxt 3** and is designed to work seamlessly with the [Laravel backend](https://github.com/Hjordt98/shopping_list_backend).

## Technological Focus: Nuxt 3 Frontend

This section highlights the Nuxt 3-specific aspects of the project.

- **Nuxt 3 & Vue:**
  - Leveraged Nuxt 3 for its powerful SSR and modular structure, ensuring a scalable and maintainable codebase.
  - Used Vue's composition API for state management and reactivity.
- **Component Library:**
  - Integrated [DaisyUI](https://daisyui.com/) for rapid, consistent, and beautiful UI development, ensuring a modern and accessible user experience.
- **NPM Libraries:**
  - Utilized libraries such as Axios (for API calls), VeeValidate (for form validation), and others to streamline development and enforce best practices.
- **CRUD Functionality:**
  - Implemented robust CRUD operations for shopping lists and items, with clear separation of concerns and error handling.
- **Collaboration Features:**
  - Developed features for sharing lists and managing collaborators, handling different user roles and permissions in the UI.
- **Coding Standards:**
  - Focused on clean, readable code with reusable components, proper state management, and clear API integration.
  - Emphasized maintainability and scalability, while always looking for ways to improve.

## Bird's Eye View

This section provides a broader perspective on the project as a whole.

- **Full-Stack Solution:**
  - The app consists of a Nuxt 3 frontend and a Laravel backend, communicating via RESTful APIs.
- **Core Features:**
  - User authentication (register, login, logout)
  - Create, edit, and delete shopping lists and items
  - Mark items as bought or favorite
  - Share lists and collaborate with other users
  - View all favorite items across lists
- **Database & Data Modeling:**
  - Used Laravel factories and seeders to generate realistic test data, ensuring the app is robust and easy to demo.
  - The database schema was designed to support both personal and shared lists, with clear relationships between users, lists, and items.
- **Project Learnings:**
  - This project taught me how to architect a full-stack application, handle real-world collaboration features, and maintain a clean separation between frontend and backend responsibilities.

## Setup & Usage

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```
The app will be available at [http://localhost:3000](http://localhost:3000).

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

For more details, see the [Nuxt documentation](https://nuxt.com/docs/getting-started/introduction).
